# 다각형 각 실험실

중학교 수학 '다각형의 내각과 외각' 수업용 웹 도구 두 가지입니다. 각각 파일 하나로 동작하며, 휴대폰·태블릿·전자칠판 화면을 모두 지원합니다.

| 도구 | 주소 | 내용 |
| --- | --- | --- |
| 외각의 합 실험실 | `/` (index.html) | 자동차가 다각형 둘레를 돌며 꺾은 각(외각)을 모아 외각의 합 360° 탐구 |
| 내각의 합 탐구실 | `/interior/` | 다각형을 삼각형으로 나누고 각을 모아 내각의 합 180° × (n − 2) 탐구 |

## 외각의 합 실험실
- 삼각형 ~ 팔각형, 꼭짓점을 끌어 모양 바꾸기
- 각도 직접 입력(내각만큼 도는 흔한 실수 시연) / 자동으로 돌기
- 외각 모으기: 외각들이 한가운데 모여 360° 원 완성
- 응용: 오목다각형(왼쪽으로 도는 외각은 −), 별다각형(두 바퀴 → 720°)

## 내각의 합 탐구실
- 삼각형 ~ 십이각형, 세 가지 나누기(한 꼭짓점에서 / 대각선 직접 / 내부의 한 점)
- 꼭짓점마다 내각 = 나뉜 각들의 합을 말풍선으로 표시
- 세 각을 모아 180° 반원 만들기
- 규칙 찾기 표(칸을 하나씩 공개), 오목다각형 스위치

## 공통
확인 문제(매번 새로 만들어지는 4지선다), 사용법 안내, 각도 숫자 켜고 끄기, 전자칠판용 칠판 모드.
