# 외각의 합 실험실

자동차가 다각형 둘레를 한 바퀴 돌며 꼭짓점마다 꺾은 각(외각)을 모아, 외각의 합이 360°임을 탐구하는 중학교 수학 수업 도구입니다.

## 기능
- 삼각형 ~ 팔각형, 꼭짓점을 끌어 모양 바꾸기
- 각도 직접 입력(내각만큼 도는 흔한 실수 시연) / 자동으로 돌기
- 외각 모으기: 외각들이 한가운데 모여 360° 원 완성
- 응용: 오목다각형(왼쪽으로 도는 외각은 −), 별다각형(두 바퀴 → 720°)
- 확인 문제(매번 새로 만들어지는 4지선다), 사용법 안내
- 전자칠판용 칠판 모드, 휴대폰·태블릿 화면 지원

## 사용
`index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
